# 🧠 Human Brain Interactive Simulation

An interactive educational web project that helps users explore the structure and functions of the human brain.

## 📌 Project Description

The Human Brain Interactive Simulation is a web-based application created using HTML, CSS, and JavaScript.

Users can interact with different highlighted regions of the brain to learn about their functions and real-life examples.

## ✨ Features

- 🧠 Interactive realistic brain image
- ✨ Glowing clickable brain regions
- 📚 Information about major brain regions
- 👩‍💼 Frontal Lobe
- 🖐️ Parietal Lobe
- 🎧 Temporal Lobe
- 👁️ Occipital Lobe
- 🤸 Cerebellum
- ❤️ Brainstem
- ⚡ Neural signal animation
- 🎯 Interactive brain knowledge quiz
- 📱 Responsive design for different screen sizes
- 🎨 Animated and modern user interface
